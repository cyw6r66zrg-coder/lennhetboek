# lennhetboek.nl

Statische website voor het boek *Lenn*. Geen build-stap: gewone HTML, CSS en een beetje JavaScript.

- `index.html` – de homepage
- `privacy.html` – privacyverklaring
- `style.css` – opmaak (kleuren en maten bovenaan in `:root`)
- `config.js` – prijs en adres van het formulier
- `form.js` – controle en verzending van het inschrijfformulier
- `apps-script/` – het script dat inschrijvingen in een Google Spreadsheet zet (zie `LEESMIJ.md`)

Lokaal bekijken: `python3 -m http.server` en open http://localhost:8000
